## v0.14.1 开场绘本数值下调

- 开场绘本 18 位 Boss 的生命整体下调，最强（空白小王·未写完的结局）由 960 降至 **300**，其余依次递减：
  20 / 25 / 32 / 40 / 50 / 62 / 75 / 90 / 106 / 124 / 143 / 163 / 184 / 206 / 229 / 253 / 276 / 300。
- 18 位 Boss 的接触伤害与招式伤害全部减半（接触 1～5，招式 2～6）；空白小王的纸星大招由 13 降至 **7**。
- 防御、阶段阈值、弹幕数量、召唤方式、掉落、武器与封印规则均未改动；4 位四材试炼小兵与 3 位极致弱化神明不受影响。
- 专家模式生命 ×1.25／伤害 ×1.2，大师模式生命 ×1.5／伤害 ×1.4 的倍率不变，按新基数计算。

## v0.14.0 金属与宝石的微型试炼

- 为绘本新增四位无时期限制的微型 Boss：铜试炼小兵·铆点、银试炼小兵·月痕、金试炼小兵·叮当、钻石试炼小兵·折光；它们排在三位极致弱化神明之前，经典模式生命值分别为1、2、4、8。
- 四位试炼小兵各自新增一把专属纪念武器：铜锈短棍、微光银针、鎏金铃锤和碎钻星芒。四把武器伤害均为1，使用时间为55至70，明显慢于免费练习木剑，不参与合成。
- 铜锈短棍为缓慢近战武器，微光银针为不消耗弹药的缓慢远程武器，鎏金铃锤为消耗4点魔力的慢速魔法武器，碎钻星芒召唤一颗缓慢追踪的钻石伙伴，占用1个仆从栏。
- 四把武器均可在18场寓言试炼中使用；普通模式直接掉落，专家与大师模式放入对应宝藏袋。Boss Checklist的收藏品列表同步加入四把武器。
- 新增四张独立武器贴图、钻石伙伴贴图及中英文名称和工具提示。版本升级至 v0.14.0。

## v0.12.0 未写完的开场

- 空手、零材料制作「未写完的开场绘本」，手持左键打开章节面板；18场试炼按当前世界顺序解锁。Boss Checklist安装时仅显示已发现章节。
- **包括已有世界在内，未通关且未跳过的世界会持续施加原版创意震撼，无法挖掘或放置方块。** 击败第17只只解锁隐藏结局；击败第18只才解除封印并开放自由重战。
- 绘本提供永久跳过的二次确认。跳过影响整个世界，不补发掉落、不伪造击败记录，之后不能再挑战这18只。多人仅房主可确认，专用服务器可执行 `fable skip confirm`。
- 封印期间试炼内以初始工具或绘本武器战斗，生命上限100、魔力上限20；需要卸下护甲饰品并离开坐骑。空中临时试炼台不改写真实方块；绘本可免费领取备用练习木剑及补领已击败章节的武器。
- 18把微弱武器、3件纸页护甲、4把升级武器和11伤害的「未完之刃」。隐藏Boss掉落未写之页，制作纸页小工台与装备；没有为每只迷你Boss添加高强度护甲、宝藏袋或圣物。
- 原有8只迷你Boss的经典生命按时期调整为90、145、200、310、435、580、735、880；不更改它们的AI。树脂幼兽与其他正式Boss保持原有数值。
- 新Boss主体使用内置绘图生成的透明图集，技术裁切与最近邻缩放；武器、物品与穿戴贴图扩展现有代码原生像素资源流程。图集及处理源码位于 `work/fable-art/`。
- 开发验证：`work/verify-fable-headless.ps1` 验证原生数值/流程/AI；`work/verify-fable-client.ps1` 验证图形加载及全部旧内容回归。两者都支持 `-WithoutChecklist`。无界面通过不等于图形验证通过。
