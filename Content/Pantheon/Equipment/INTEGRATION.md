## Safety and network
Owner-created projectiles,120 live shot cap perowner,2slot minions, native buff sacrifice/dismissal/target preference, no attack-through-wall.
Remote projectile serializes aim/origin/direction/age; rejects NaN, invalid kind/weapon and truncated payload before state commit.
Skill server checks sender player, active/dead, actual worn full set and cooldown; accepts no client position/heal/damage inputs.
Cooldown-only client snapshots can ONLY increase cooldown, never shorten; arbitrary clients can at worst lengthen their own cooldown. Full active skill snapshot only accepted by clients.
Cooldowns24 persist unequip/death/binary player save. Timed benefits clear on unequip, so gear swapping doesn't stack guards.
Expert healing uses standard local-owner vanilla hurt/hit authority, max120/220/300, never restores a dead player. No new heal/teleport network packet.
All protective effects leave >=1 final damage; no ConsumableDodge, revive, immune frame write, or forced movement. Enemy-origin classification reuses read-only Ascendant helper.
Primary hit counting globally max1/10ticks perplayer; target dummies/friendlies/secondary effects excluded, no recursive proc chains.
Gate accessory intentionally grants local movement inside15tiles of damage-origin for3sec, not teleport; tooltip truthful.
Furnace automatically discharges at100heat (not an undocumented second key).
